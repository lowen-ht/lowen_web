# 财报突破跟随策略（PEAD / 聪明钱跟随）

> 来源：知乎回答（作者 1234）关于"美股跟随机构"的经验策略。本文对其逻辑做结构化解析，并给出在 **NVDA** 上的可执行方案与验证代码。本文为学习笔记，**非投资建议**。

## 一句话概括

在流动性充足的美股大盘股上，**[[investment-knowledge-base#财报|财报]]窗口出现的"巨量 + 大波动 + 趋势反转 + 站稳"是机构大规模调仓的痕迹**；沿该方向持有到下一次财报，并严格止损，是一种方向中性的事件驱动策略。其学术内核是**[[investment-knowledge-base#PEAD|盈余公告后漂移]]（Post-Earnings Announcement Drift, PEAD）**。

## 一、核心逻辑拆解

### 1. 机构痕迹明显：微观结构视角
美股大盘股由机构（共同基金、对冲基金、养老金、[[investment-knowledge-base#ETF|ETF]] [[investment-knowledge-base#做市商|做市商]]）主导，订单规模天然远大于散户。即便机构用算法拆单（TWAP/VWAP）、走暗池隐藏，但**基于基本面的"信念型"调仓**体量太大，仍会以"异常成交量（volume shock）"暴露。成交量本身是信息不对称的代理变量（Easley, López de Prado & O'Hara 的 VPIN 框架，2012；Lee & Ready 的逐笔交易分类法，1991）。

### 2. "万吨巨轮"：成本信号
机构调动大资金有成本与审查，轻率下单概率低。它"开动"这一动作本身，就是一个被市场解读为"优势信息已被行动化"的**昂贵信号**。小资金者不与方向博弈，而是**搭便车（free-ride）**——即评论所谓"利益共同体 / 跟在屁股后面"。

### 3. 方向中性：搭便车
策略不预判多空，只跟随突破方向（做多或[[investment-knowledge-base#做空与空头|做空]]都行），降低了"猜方向"的负担。

### 4. 美股 vs A 股：市场结构差异
- **美股**：机构主导、分析师覆盖密集、Reg FD 限制选择性披露、流动性连续 → 机构脚印更"可读"、趋势更连续。
- **A 股**：散户占比高、政策/国家队干预多、"庄股"与操纵历史、[[investment-knowledge-base#T+1 结算|T+1]] 与涨跌停限制 → 机构趋势的"利益共同体"感弱。
- 评价：结构性差异**真实存在**，但"美股规律性强多了"是经验泛化，A 股同样存在机构[[investment-knowledge-base#动量|动量]]效应，只是噪音与政策冲击更大。

### 5. 可检验的操作规则
1. **流动性过滤**：日均成交额（[[investment-knowledge-base#ADV20|ADV]]）> 3 亿美元——保证"机构真的在那儿"，且你不是边际定价者；
2. **事件窗口**：财报期；
3. **信号**：大波动 + 巨量 + **改变原趋势** + **站稳当时价格**；
4. **预测**：下一次财报前沿该方向持续；
5. **风控**：严格止损。

这套规则几乎就是 **PEAD** 的工程化表述。

### 6. 止损的两点理由（逻辑自洽）
- 机构也会看走眼（确认信号 ≠ 必然正确）；
- 宏观不可预测（关税、美联储/鲍威尔）——任何个股策略的系统性外生风险。

## 二、学术与实证支撑

| 现象 | 对应文献 | 结论 |
|---|---|---|
| 财报有信息含量、价格会调整 | Ball & Brown (1968) | 盈余公告携带可被定价的信息 |
| 公告后股价沿意外方向**持续漂移** | Bernard & Thomas (1989/1990) | PEAD：漂移可持续约 60 个交易日 |
| 中期动量 | Jegadeesh & Titman (1993) | 赢家/输家组合中期延续 |
| 成交量暴露知情交易 | Easley et al. (2012) VPIN | 异常成交量与逆向选择风险正相关 |

> 关键提醒：PEAD 被发现后被大量套利，整体**衰减**了，但在**高流动性、高关注度的财报大票**上仍较稳定——这正好与"ADV > 3 亿"的过滤条件吻合。

## 三、"站稳"为什么关键 & 策略可操作化

- **"站稳"是确认过滤器**：把"假突破 / 利好出尽（sell the news）"挡在门外，代价是你**晚进场、吃不到最肥的一段**（确认滞后）。
- **持有周期 = 一个财报周期**：下一次财报会重置预期，所以逻辑上持有到下次财报是合理的止盈/重新评估节点。
- **ADV > 3 亿**同时解决流动性（[[investment-knowledge-base#滑点|滑点]]小）与反操纵（小票易被人为放量骗线）。

## 四、风险与失效场景（必须正视）

1. **[[investment-knowledge-base#幸存者偏差|幸存者偏差]]**：作者只举了 MSFT / ORCL / EBAY 等"奏效"例子；评估策略要看**基础概率**（失败率、平均盈亏比）。
2. **确认滞后吞噬漂移**：等你确认"站稳"，PEAD 最好的一段往往已过。
3. **宏观压倒个股**：关税、利率、地缘——作者自己承认，这类风险会让"巨轮"也翻车。
4. **[[investment-knowledge-base#拥挤交易|拥挤交易]]**：若人人跟同一信号，边缘优势被压缩；"巨轮掉头"时跟随者最易被踩踏。
5. **适用范围有限**：这是**个股财报**策略，对无财报周期的资产（如黄金 GLD）**不适用**。

## 五、在 NVDA 上如何执行（操作手册）

NVDA 是该策略的**教科书级标的**：日均成交额长期远超 3 亿美元（常达数百亿）、机构主导、财报波动剧烈（常 ±5%~±10%）。执行步骤：

1. **标记财报日历**：NVDA [[investment-knowledge-base#财年|财年]]与自然年错开，通常于 2 月、5 月、8 月、11 月发布季度财报（以 NVIDIA Investor Relations 公告为准）。把这四个窗口设为"观察日"。
2. **财报后首个交易日，读取信号**：
   - [[investment-knowledge-base#收盘对收盘收益|当日涨跌]]幅（事件收益）；
   - 当日成交量 / 前 20 日均量（**[[investment-knowledge-base#量比|量比]]**，> 2 视为"巨量"）；
   - 是否改变此前 1–2 个月趋势；
   - 随后 3–5 个交易日是否"站稳"（不[[investment-knowledge-base#空头回补|回补]]缺口、价格维持在事件日收盘的有利一侧）。
3. **满足条件则沿方向建仓**：
   - [[investment-knowledge-base#多头与仓位|多头]]：事件日大涨 + 巨量 + 站稳 → 买入；
   - 空头/回避：事件日大跌 + 巨量 + 跌破 → 不抄底，等方向确认。
   - 仓位遵循 [[risk-management]]：单票不超过组合 10–15%，新手更小。
4. **持有至下一次财报**：约一个季度；用**[[investment-knowledge-base#止损单|跟踪止损]]（Trailing Stop）**或固定止损（如 −8%~−15%）保护，详见 [[order-types]] 与 [[risk-management]]。
5. **先用代码[[investment-knowledge-base#回测|回测]]，再下注**：运行 `code/earnings_drift_check.py` 拉取 NVDA 最近若干次财报的"事件收益 / 量比 / 后续 5/20/60 日漂移"，亲自看规律是否成立、失败案例长什么样。

> ⚠️ NVDA 波动极大，且受**中国[[investment-knowledge-base#出口管制|出口管制]]**等地缘风险影响（见 [[nvda-analysis]]）。宏观外生冲击可能让"巨轮"也翻车——止损不是可选项，而是纪律。

## 六、验证代码

见 `code/earnings_drift_check.py`：输入 ticker（默认 NVDA），自动输出最近 N 次财报的**事件收益、量比、以及公告后 5/20/60 个交易日的漂移**，并给出"巨量 + 大波动 + 站稳"的简化信号判定。用法：

```bash
cd content/Investment/code
pip install -r requirements.txt
python earnings_drift_check.py --symbol NVDA --n 8
```

## 七、结论

这是一套**逻辑自洽、且有 PEAD/动量文献支撑**的"美股大盘股财报突破跟随"方法：流动性过滤 + 巨量确认 + 趋势改变 + 站稳 + 持有至下次财报 + 严格止损。它比纯技术指标更"接地气"，但**不是免费午餐**——确认滞后、宏观外生风险、拥挤与幸存者偏差都会侵蚀[[investment-knowledge-base#方向命中率|胜率]]。对 A 股"无利益共同体"的感受，反映的是真实的市场结构差异，但结论不宜绝对化。
