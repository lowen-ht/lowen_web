# 复盘补充 · 新闻与事件层

> **角色分工**：
> - [[prediction-log]] — 程序生成的**量化评分**（Brier / RPS / 方向 / 归因残差），每次运行自动重建；
> - **本页** — 每日自动化追加的**定性归因**（当天发生了什么新闻、哪个情景分支被触发、为什么当时的信号没捕捉到）；按日期追加，**不重建**；
> - [[lessons]] — 从复盘中提炼、可复用的**规则与经验**（每次预测前必读）。
>
> 三者互不覆盖：数字归台账，故事归本页，可复用规则归经验库。本页不构成投资建议。

## 2026-11-05 回测演练（**非实盘预测**）

> 来源：`code/demo_backfill.py`，严格截断到 11-04 收盘的信息重建预测，再与真实 11-05 行情对照。仅用于验证闭环，**不计入**实盘记分板。

- **实际**：收 $181.60（−9.26%），日内 −7.38%，费半 −12.25%，VIX 升至 28.18，成交额约 $567 亿。
- **当日已知背景**：11-03 中期选举民主党夺回参众两院后，强监管表态密集；同时市场在消化四大 CSP 的 capex 与自由现金流背离、循环融资与 $2,790 亿供应承诺带来的资产负债表疑虑。特朗普 11-05 公开把跌幅归因于选举结果。
- **计划内事件**：无财报、无 FOMC。冲击是**政治预期 + 拥挤仓位去杠杆 + 负 Gamma** 的叠加，不是单一公告 → 属于「计划外 / 结构性」冲击，历史基准率模型天然无法覆盖。
- **与预测对照**：预测众数 `flat`（41.0%）、`crash` 仅 9.7%；实际落在 `crash`，80% 区间被击穿，Brier 0.541、D 级。**方向略偏空不算大错，错的是分布太窄**。
- **有效信号**：L5 板块 beta 与残差分解完全正确（费半 × 0.65 = −7.99%，残差仅 −1.26%），准确指出这是系统性而非个股事件；L3 波动率其实已抬升，但未被用于加宽尾部。
- **失效信号**：L2 的「小缺口 + 低波动」匹配条件（n=179）把当日归入低风险档；L6 的政策状态机只记录了「表态」，没有把「表态密集 + 高拥挤仓位」编码为尾部风险。
- **升级为候选**：三条（尾部加宽 / 板块极端日条件分布 / 遗漏风险的显式证伪条件），已写入 [[lessons]] 候选区，**保持 `status=candidate`，待实盘复盘确认后才生效**。
