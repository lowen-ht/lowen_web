# 经验库 · 每次预测前必读

> ⛔ **硬约束**：`predict.py` 在生成任何预测之前会读取本文件，**文件缺失或为空时直接拒绝出预测**。预测记录中写入本文件当时的 sha256 作为「已读」证据。
>
> **使用顺序**：① 通读下方 ACTIVE 规则 → ② 看最近 3 条归档经验的结论 → ③ 检查候选区是否有该升级的规则 → ④ 才允许生成新预测。
>
> 本文件**只记录可复用的经验与规则**，完整逐日复盘在 [[prediction-log]]。规则宁少勿滥：一天的结果不构成规律。

## 读前检查清单（每次预测前逐项确认）

- [ ] 上一次预测是否已复盘并打分？未复盘 → **停止**，先跑复盘。
- [ ] 今日是否为美股交易日？休市 / 半日市 → 跳过或显著加宽分布。
- [ ] 开盘前是否还有计划内数据发布（非农 / CPI / FOMC）？有 → 只加宽尾部，不偷偷选方向。
- [ ] 盘前缺口代理与正式开盘缺口是否可能大幅偏离？偏离风险高 → 降低该倾斜权重。
- [ ] 本次是否想「因为昨天错了」而临时改规则？**不允许**——规则变更必须走候选 → 确认 → ACTIVE 流程。
- [ ] 匹配历史样本数是否 <30？是 → 以无条件基准率为主，弱化倾斜。
- [ ] 是否写下了「什么会证明我错」？没写 → 预测不完整。

## ACTIVE 规则（程序会解析并作用于预测）

> 语法：`- [L-编号] 规则描述 | tilt=方向:权重 | [overrides=倾斜名] | status=active`
> 方向可选 `up` / `down` / `flat` / `widen` / `follow_sox`。权重上限由 `config.json` 的 `max_tilt_logodds` 截断。
> **`overrides=` 表示覆盖同名预注册倾斜，而不是叠加**——经验要取代默认值，不能与默认值重复计权。
> **只有 `status=active` 会被读取**；候选区里的 `status=candidate` 不生效。无 `tilt=` 的规则是叙事型纪律，只被阅读、不参与计算。

- [L-001] 当板块指数单日波动 >5% 时，个股涨跌主要来自系统性因子，先按板块 beta 归因、再谈个股逻辑；预测方向跟随费半而非个股技术信号 | tilt=follow_sox:0.16 | overrides=sector_beta_spillover | status=active
- [L-002] 媒体给出的前瞻市盈率出现互斥口径（本次见到 12.9x/16.5x/16.6x/21.5x）时，禁止用「便宜/贵」判断方向；估值只作幅度与风险背景 | status=active
- [L-003] 财报、非农、FOMC 等计划内事件当日，期权隐含波动率定价的是**幅度**而非方向；强制加宽两尾，不允许借事件选边 | tilt=widen:0.12 | overrides=scheduled_macro_event | status=active
- [L-004] 跌破 200 日均线且 PEAD「站稳」条件未确认时，不抄底；保持轻微下偏，等待 3–5 个交易日确认 | tilt=down:0.08 | status=active
- [L-005] 样本 <30 的命中率、胜率、Sharpe 不得用于调整规则；只用于提出待验证假设 | tilt=flat:0.04 | status=active
- [L-006] 预测必须报概率分布而非点位；最大桶概率 >45% 视为过度自信信号，需主动检查是否漏了计划外风险 | tilt=widen:0.06 | status=active

**规则来源**：L-001 来自 2026-11-05 全板块去风险（费半 −12.25%、纳指 −5.52%，NVDA 跌幅反而小于多数同业）；L-002 来自口径冲突核验；L-003 来自 Cboe 对 Mag7 财报隐含波动率的说明；L-004 来自 [[earnings-drift-strategy]] 的四条件纪律；L-005/L-006 来自严格适当评分规则与多重检验纪律（Bailey & López de Prado 2014）。

## 已归档经验（复盘自动追加，人工确认后在此写结论）

> `review.py` 会在候选区追加带日期的候选规则。每日复盘时把**成立且可复用**的升级为 ACTIVE（赋予 L-0xx 编号），把不成立的在此写明「为何不成立」，形成可追溯的修订史。

### 2026-11-06 建库说明（尚未有实盘复盘样本）

- 首个预测之前的**已知负面实证**：本仓库 `[[earnings-drift-strategy]]` 在 2023-10~2026-10 的 8 次财报中，naive「巨量+大波动+站稳」信号**一次未触发**，且多数财报后出现反转。因此任何「跟随巨轮」的直觉在 NVDA 上都先按**反证**处理。
- **已知数据卫生教训**：同为 2026-11-05，媒体出现 −9.26%（收盘）/ −9.18% / −7.3% / −6.94% 等多个数字，只有 **$181.60 / −9.26%** 是收盘值；误用盘中快照会污染事件收益。量比必须用 ADV20，不能用前一日作代理。
- **已知归因教训**：把「民主党赢得中期选举」直接写成「NVDA 大跌的原因」漏掉了传导层（审批/电力→交付时点）与放大层（拥挤仓位、去杠杆、负 Gamma、跌破 200 日线）。因果要分层，复盘归因同样要分层。
- **口径铁律**：NVDA 财年 1 月底结束，FY2027 覆盖 2026-02~2027-01；讨论估值必须同时声明「哪个财年 / 哪个 EPS / 哪个价格时点」。
- **建库期修正（开盘前完成，此后不再回改）**：首版代码把 ACTIVE 规则与预注册倾斜**重复计权**（L-001 与 `sector_beta_spillover`、L-003 与 `scheduled_macro_event` 各加了两遍），使首期预测过度偏多。已实现 `overrides=` 语义并重建首期预测。**教训：规则库与默认参数之间必须显式声明「覆盖」还是「叠加」，否则经验会悄悄放大而非修正模型。**

### 2026-11-05 回测演练复盘（**非实盘预测**，仅用于验证闭环）

> 用 `code/demo_backfill.py` 严格截断到 2026-11-04 收盘的信息，重建「若当日盘前做预测会说什么」，再与真实 11-05 OHLCV 对照。此记录**不计入**实盘记分板。

- **预测**：`crash 9.7% / down 18.1% / flat 41.0% / up 24.7% / surge 6.5%`，P(涨) 51.7%，E[r] −0.03%，众数 `flat`。
- **实际**：收 $181.60，**−9.26%**（`crash`）；开盘缺口 −2.03%、日内 −7.38%；费半 −12.25%。
- **评分**：方向 MISS ｜ Brier **0.541** ｜ RPS **0.360** ｜ 80% 区间 **未覆盖** ｜ E[r] 误差 9.23pp ｜ 综合 **44 分（D）**。
- **归因**：费半 × beta 0.65 = **−7.99%**，个股残差仅 **−1.26%** → 这是**板块系统性去风险**，不是个股基本面；但模型用的是「小缺口 + 低波动」匹配条件（n=179），完全没把板块极端日纳入条件，因此尾部被严重低估。
- **结论（可复用）**：当板块指数单日 >5% 时，个股预测先验必须切换到「板块极端日条件分布」；无条件基准率在这类日子系统性低估尾部。这与 L-001 的方向一致，但**强度不够**——方向对了、幅度错了，同样算失准。
