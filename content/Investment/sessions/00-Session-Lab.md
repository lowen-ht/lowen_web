# 开盘 / 收盘学习板块 · NVDA

> **这是做什么的**：每个美股交易日**开盘前**，对 NVDA 当日「收盘对收盘」涨跌给出**概率分布**；**下一个交易日开盘前**，自动对上一次预测打分、分析误差原因，并把经验写进独立文件。目标不是「猜对」，而是**训练校准能力**（calibration）——让说「70%」的时候，长期真的发生约 70%。
>
> **本板块不是交易系统**，不产生买卖指令，不构成投资建议。

---

## 1. 时间窗口（务必区分夏令时）

美股常规交易 **09:30–16:00 美东**。换算北京时间（UTC+8）：

| 时段 | 冬令时 EST（11 月初 ~ 3 月中） | 夏令时 EDT（3 月中 ~ 11 月初） |
|---|---|---|
| 开盘 | **22:30** | **21:30** |
| 收盘 | **次日 05:00** | **次日 04:00** |
| 盘前预测发布 | 北京时间 **20:30**（提前 1~2 小时） | 同左 |
| 复盘执行 | 与次日盘前预测同一次运行，先复盘再预测 | 同左 |

- 2026-11-01 已切换 EST，故 **2026-11-06 开盘为北京时间 22:30**。
- 半日市（感恩节后一日 13:00 ET、圣诞前夜 13:00 ET）与休市日见 [NYSE 官方日历](https://www.nyse.com/markets/hours-calendars)；程序内置 2026–2027 休市表，休市日**跳过、不生成预测**。
- 美东 **08:30**（北京时间 21:30 / 22:30）常发布非农、CPI 等数据，可能落在预测发布之后、开盘之前。这是**刻意保留的设计**：预测必须写清「若数据超预期会怎样」的情景分支，而不是等数据出来再写方向——否则就变成事后解释。

## 2. 四条铁律

1. **先复盘，后预测**：任何一次新预测前，必须完成上一次预测的准确度计算与归因。
2. **预测前必读 [[lessons]]**：由 `predict.py` **硬性强制**——文件缺失、为空或读取失败时程序直接拒绝出预测；预测记录里写入 `lessons.md` 的 sha256 作为「已读」证据。
3. **冻结不可回改**：预测写入时带 UTC 时间戳 + 内容 sha256；收盘后只允许在**独立字段**追加结果，绝不修改原预测分布。
4. **写清「什么会证明我错」**：每条预测必须包含可证伪条件；没有证伪条件的观点不计入记分板。

## 3. 文件职责（互相独立）

| 文件 | 角色 | 谁写 |
|---|---|---|
| [[lessons]] | **经验库 · 每次预测前必读**。ACTIVE 规则会被程序解析并作用于预测；候选规则由复盘自动追加，需确认后才升级 | `review.py` 追加候选 / 每日复盘确认升级 |

## 4. 每日闭环

```
20:30 北京时间（交易日）
  │
  ├─ 1  刷新真实日线（NVDA / 费半 / VIX / QQQ / AMD / SPX）
  ├─ 2  取盘前快照 + 当日计划内事件（写入 data/premarket.json）
  ├─ 3  【复盘】读取上一次冻结预测 → 用已收盘的真实 OHLCV 打分
  │        ├─ 方向命中 / Brier / RPS / 区间覆盖 / 期望误差
  │        ├─ 归因：计划内事件 · 板块 beta · 缺口反转 · 个股特异残差
  │        └─ 生成「候选经验」追加进 lessons.md（status=candidate）
  ├─ 4  【确认】复盘者把成立的候选规则升级为 status=active 并编号
  ├─ 5  【预测】读取 lessons.md（含刚写入的经验）→ 生成 5 档概率分布 → 冻结
  └─ 6  重建每日简报与事件日历
```

第 4 步是**唯一需要判断力的环节**：候选经验不会被自动生效，避免把一天噪音固化成永久规则。这也是「学习」与「自动拟合」的分界线。

## 5. 预测格式与评分

预测目标是**收盘对收盘收益率**，分成 5 个有序档：`≤-3% / -3~-1% / -1~+1% / +1~+3% / ≥+3%`。输出每档概率、P(涨)、期望收益、80% 区间、匹配历史样本数、所用倾斜规则及依据。

| 指标 | 定义 | 为什么用它 |
|---|---|---|
| 方向命中 | `P(涨)>=0.5` 与实际涨跌符号是否一致 | 最直观，但容易被 50/50 糊弄 |
| **多分类 Brier** | `Σ(pₖ−oₖ)²/2` | **严格适当评分规则**：只有报真实概率才使期望得分最优，无法靠装自信刷分 |
| **RPS** | 有序累计概率误差 | 惩罚「错得离谱」：预测暴跌却大涨，比预测小跌更糟 |
| 80% 区间覆盖 | 实际档位是否落在区间内 | 长期显著低于 80% = 过度自信 |
| 期望收益绝对误差 | `\|E[r]−实际\|` | 检查中心估计是否系统性偏移 |

> 来源：Brier (1950)；Gneiting & Raftery (2007) 严格适当评分规则；Brier 分解 = 校准 − 分辨力 + 不确定性。**样本 <30 时任何命中率都不具统计意义**，记分板会明确标注。

## 6. 预测的先验从哪里来（不是拍脑袋）

- **本标的自身的历史基准率**：用 5 年真实日线，按「缺口方向 + 缺口量级带 + 波动率状态」匹配历史交易日，统计 5 档频率；拉普拉斯平滑防止 0/1 概率；**匹配样本数必须一并披露**（见 `../daily/` 的基准率表）。
- **预先注册的倾斜（tilts）**：固定权重、不针对近期结果拟合，每条都有文献或机制依据：
  - 价格低于 200 日均线 → 下偏（Jegadeesh & Titman 1993 动量 / CTA 风控）
  - RSI(14) < 30 → 短均值回复上偏（Wilder 1978）
  - 正隔夜缺口 → 轻微下偏（Berkman, Koch, Tuttle & Zhang 2012 开盘反转；该效应在**负**隔夜收益后更强，故权重刻意压低）
  - 高已实现波动率 → 向中心收缩（Moreira & Muir 2017 波动率管理）
  - 计划内宏观数据 → **加宽尾部而非选方向**（Cboe：期权隐含波动率定价幅度，不定价方向）
  - 板块 beta 溢出 → 跟随费半方向（Lou/Polk/Skouras 2019 隔夜—日内「拉锯」）
- **经验库 ACTIVE 规则最后应用**：带 `overrides=<倾斜名>` 的规则**覆盖**同名预注册权重（不叠加，避免重复计权），其余规则作为附加倾斜；每条覆盖与附加都写进预测记录，可追溯。
- **「开盘后怎么走」的分解**：`收盘对收盘 ≈ 隔夜缺口 + open→close`。盘前缺口已知时，预测卡片会额外给出**隐含的日内期望**——正值代表缺口延续，负值代表缺口回吐/开盘反转；复盘时单独给这一判断打分。

## 7. 已知局限（必须一直挂在墙上）

1. **盘前报价 ≠ 正式开盘价**：程序用盘前涨跌代理隔夜缺口，偏离可能超过 1pp，是匹配条件的主要误差源。
2. **历史基准率是条件频率，不是因果**：5 年样本约 1000+ 根，但细分匹配后常不足 30 例，置信度低。
3. **计划外消息无法建模**：公司公告、政策突变、地缘事件会让整套分布失效；复盘时归为「个股特异残差」而不是硬找解释。
4. **不做交易**：不回测该预测策略、不计入盈亏、不设仓位。校准练习与可执行策略之间还隔着成本、容量与执行。
5. **自动化会失败**：网络、数据源、休市日都可能导致跳过；日志会记录跳过原因，不会补造数据。
